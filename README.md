▶️ How to Run

Install the required libraries:

pip install numpy pandas matplotlib

Run the programs in a Python environment:

python python_basics.py
python numpy_pandas_practice.py
python retail_sales_analysis.py
python retail_sales_visualization.py

Keep the CSV dataset in the same working directory as the retail sales scripts.
